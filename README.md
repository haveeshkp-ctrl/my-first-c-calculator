
# C Calculator

My first C programming project!

## About
A simple calculator built using the C programming language. It takes two numbers and an operator from the user and displays the result.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Checks for invalid number input

## Requirements
- GCC compiler
- Visual Studio Code (optional)

## How to Run

Compile the program:

```bash
gcc project_1.c -o calculator.exe
```

Run it on Windows PowerShell:

```powershell
.\calculator.exe
```
